# 推广策略：按场景与指标合看三个时间尺度

## 输入与分析单位

输入为目标商品的四组汇总与8个完整自然周推广数据。分析单位是“商品＋推广场景＋指标”；新采集采用target-only快照合同；历史证据读取目标succItemValue与目标关键词succItem。接口所需本店商品参数由tbcli自动准备，图表和解读仅采用目标商品侧值；目标关键词采用succItem。先核对[来源边界](analysis-boundaries.md)。请求日期和已核实的实际覆盖分别记录；未回显日期不能称已验证实际覆盖。

## 从证据形成一句结论

对每项指标，先核对近7天／前7天、近30天／前30天，再看8个完整周。7天回答近期变化，30天回答较长周期表现，自然周回答持续性与拐点。窗口重叠只作不同尺度对照，不算独立验证。

原值分为exact、range、missing。精确值可视为上下界相同的范围，单位保持源口径。比较必须是同场景、同指标、同长度的周期：

- 本期下界 > 前期上界：本期严格高于前期。
- 本期上界 < 前期下界：本期严格低于前期。
- 两个非退化区间相同：仍落在同一区间，不能确认实际持平。
- 区间有重叠或仅相接：无法确认严格升降。相接时最多说明不高于/不低于的边界关系；没有开闭区间定义时不进一步强化判断。
- 精确值相同可说明该精确值不变；一方缺失则该比较未知。

周趋势逐相邻周采用同一规则；缺失切断连续性。只报告确有证据的连续变化，不把区间中点连线当真实趋势；同一档位连着出现不能证明没有波动。最新自然周与近7天相同时，不重复计为独立证据。

精确金额/次数在分母大于0时可算环比，精确比例用百分点。非退化区间不取中点、不算精确环比、CPC或ROI，不据端点变化生成精确百分比。不同周期长度不直接用总量判断表现强弱。

## 各指标如何下结论

| 指标 | 综合判断 | 限制 |
|---|---|---|
| 展现次数 | 对照两组周期和8周区间，判断触达扩大/收缩/同档待定 | 展现不等于有效需求，不推断预算调整 |
| 点击次数 | 判断点击规模的区间位置、反弹或明确连续变化 | 不等于成交；各场景计数不默认可加 |
| 消耗占比 | 比较同场景比例的变化和出现范围 | 100%只按接口返回口径描述；不推断其他场景不存在或所有渠道均已覆盖 |
| 点击率 | 比较效率区间，与展现/点击方向交叉观察 | 相接不判断严格提升；不等同支付转化率，不用两个区间中点重算 |
| 点击成本 | 判断同口径成本区间升降或信息不足 | 未核实单位不擅自换算；成本降低不单独证明更有效或应扩量 |
| 直接成交额 | 判断直接归因金额的周期变化和峰谷 | 独立于经营销售额、实收、净利润；不补造归因窗口或单笔订单 |
| 直接ROI | 判断直接归因回报区间变化 | 不等于利润率；区间跨过1不能判断回报是否高于1，更不能据此判断盈利 |
| 消耗金额 | 判断投入的绝对变化和周度延续 | 缺失不补0、不从占比/CPC/点击量/ROI反推精确金额 |

规模与效率的相关变化只能产生核实问题。精确消耗、退款、商品成本、完整归因等不足时，停止预算或盈利结论；不把直接归因变化等同广告增量。

## 简明输出与交互

每个场景、每项指标输出一句综合结论和编号证据，通常三段分别覆盖7天、30天、自然周，关键范围或数字局部加粗。结论优先说最重要且证据足够的变化，例如“近期直接归因金额区间下移，较长周期变化仍不确定”；数据不足则说“只知道所在区间，暂不能判断精确变化”。完整周期表留给图表/折叠明细。

缺失指标也保留三个尺度的简短证据，明确“未返回”；缺失场景只能报告可见范围，不借用其他场景的数据。关键词空列表是来源状态，不能证明没有推广。

指标Tab和场景选择同步切换结论、编号证据与图表；图表周期切换不改变合看三个尺度的综合结论。共用口径折叠展示，影响当前判断的限制只留一行。完成后返回SKILL主线第4步，再进入独立渲染；概览最后综合三个模块。

## 来源与演进
