# 关键指标：7天、30天与自然周分析

适用：经营数据集156的关键指标分析；输入为四组周期汇总和8个完整自然周，指标含销售额、成交笔数、笔单价、访问量、营销推广点击量、自然点击量、支付转化率、加购率。先核对[通用来源边界](analysis-boundaries.md)。本页提供诊断方法，不能替代平台定义或补造业务原因。

## 分析任务与顺序

先核实商品、周期、来源和可用性，再描述规模；随后拆解量价、交叉观察流量和效率，最后对照周序列并给出核实事项。输出只属于关键指标模块，报告概览维持占位。

| 观察尺度 | 比较关系 | 问题 | 所需输出 |
|---|---|---|---|
| 7天 | 近7天／前7天 | 最近发生了什么变化？ | 规模、量价、流量与效率线索、原值和样本 |
| 30天 | 近30天／前30天 | 较长周期总体如何？ | 规模、增长结构与效率，说明周期内波动可能被汇总掩盖 |
| 自然周 | 最近8个完整周；相邻完整周 | 变化是否延续、何时转向或集中发生？ | 最新完整周环比、连续区间、峰谷、反复和缺口 |

7天与30天本期重叠，不能当作独立样本验证。滚动近7天与最新自然周可能日期不同；列出截止日期后再合看。30天不自动成为稳定、无活动干扰的基线。窗口和日期按周期计划，不自行改成日历月或当前未结束周。

## 比较计算

金额、次数类给出本期、前期、绝对差和相对环比：ΔX=X1−X0；X0>0时g=ΔX/X0。百分比展示时乘100。比例给原值和百分点差：pp=(r1−r0)×100，不能混写为相对百分比。计算保留完整精度，最后格式化。

- 前期0、本期正数：由0增至X；两期0：均为0，环比无定义；缺失：无法比较。空表、查询失败、0互不替代。
- 负数或异常比例先保留来源并标记待核对，暂缓常规效率判断。
- 同时报告绝对量和样本规模。少量成交的较大环比需结合“增加或减少几笔”理解。无预设统一经营阈值，无显著性检验输入时不声称统计显著。

## 销售额的量价拆解

R=N×P，其中N为该周期成交笔数、P为完整精度笔单价。此处R是推算销售额，不等同于实收、利润或推广直接成交额。两期字段和日期一致、N/P/R均可用时：

```text
成交笔数贡献 Cn = (N1−N0) × (P1+P0)/2
笔单价贡献   Cp = (P1−P0) × (N1+N0)/2
核对：Cn+Cp = R1−R0
```

这是把量价交互项对称分配的算术分析，不是流量、投放或调价的因果归因。优先给贡献金额和方向；净变化为0或贡献互相抵消时不强算贡献占比。平台均价缺失时不自行用0替代。使用浮点数核对允许与数值规模相适应的机器精度误差，呈现仍保留金额精度。

成交笔数说明成交规模；笔单价说明成交均值和可能的结构变化。笔单价变化不直接证明商品调价。单笔大额成交是否影响均值须由订单或商品结构证据确认。

## 流量与效率交叉观察

| 观察组合 | 可形成的线索 | 还需什么证据 |
|---|---|---|
| 访问与成交同向，转化率变化较小 | 规模变化与访问变化方向一致 | 核对访问与转化定义、渠道和活动范围 |
| 访问增加，成交未同步，转化率下降 | 新增访问与成交效率不同步 | 核对流量构成、商品页面、价格及活动，不先定为流量质量差 |
| 访问减少，成交相对稳定，转化率提高 | 当前样本中效率改善抵消了部分规模变化 | 订单量、渠道结构和统计分母 |
| 推广点击增加，自然点击减少 | 两类点击方向分化 | 推广场景与费用、自然来源、日期和归因关系 |
| 加购率与支付转化率方向分化 | 兴趣信号与支付表现不同步 | 转化窗口、行为分母、后续成交；加购不能保证成交 |

“变化较小”只在报告原值与百分点差后作相对描述，不暗设固定阈值。访问量为访问次数；两类点击量和访问量不默认可加、互斥或同分母。不直接计算付费占访问比例，也不从自然点击变化断言排名变化或广告增量。只有平台定义、分母、计数单位和归因一致且数值核对通过时，才使用访问×转化率×笔单价的精确漏斗关系；否则保留为方向性观察。经营加购率与人群模块收加率分别解释。

## 8周趋势

1. 按真实日期从早到晚排列，先报最新完整周与紧邻前周；首周无周环比。
2. 看每一相邻周的方向和原值，描述实际连续区间；缺失周切断连续性，不跳过缺口接续升降。只有端点差时不能称持续增长。
3. 指出最高、最低、单周峰值与升降交替，说明其时间位置。峰值是观察事实，不自动证明活动、大单或季节原因；8周不足以确认年度季节性或预测未来。
4. 数据完整、期间不重叠且定义确认可加时，可补充最近4周与前4周的金额／次数合计比较；缺周则该补充项不可用。笔单价只在金额和笔数可核对时按总额/总笔数加权；率的真实分母不明时，不合并、不取简单平均冒充整体率。

## 三个尺度合看

- 7天、30天同向：描述观察尺度方向一致，随后看周序列是否延续；不能仅据两个重叠窗口得出持续性结论。
- 7天改善、30天转弱：近期出现改善信号，较长周期仍弱；观察完整周是否跟进。
- 7天转弱、30天改善：近期走弱，较长周期仍保留改善；核对下降起始周和量价结构。
- 周序列反复或被单周峰值拉动：描述波动与集中情况，保留方向判断的适用区间。
- 数据不足：只输出已核实尺度；不强行给经营阶段、行业排名或竞争力评级。

上述描述不构成因果确认。未获得同行、类目或市场样本时，只比较本商品历史。

## 指标为主线的结论生成

逐项处理8个指标。对当前指标先分别核对7天环比、30天环比和8周连续性，再合成一句话；三个时间维度是证据来源，不各自展开成多份长分析。全部计算和来源仍可在分析输入与原始数据中追溯。

| 指标 | 综合结论优先回答 | 判断方法和限制 |
|---|---|---|
| 销售额 | 增长、回落还是反复，近期与较长周期是否分化？ | 先合看7天/30天方向，再用周序列核实持续性；量价贡献只在解释净变化时补充关键一项 |
| 成交笔数 | 成交规模扩大还是缩小，变化是否连续？ | 原值和绝对增减优先；低基数时说明增加/减少几笔，不放大百分比含义 |
| 笔单价 | 成交均值上升还是下降，最近是否转向？ | 比较两组环比与连续周变化；均价变化不能直接等同商品调价 |
| 访问量 | 访问扩大还是收缩，是否近期连续变化？ | 两组周期方向加周度连续区间；访问次数与人数分开 |
| 营销推广点击量 | 点击增加、回落还是反弹？ | 区分最新周反弹与8周持续增长；无费用/归因时不评价投放回报 |
| 自然点击量 | 自然触达是否变弱、持续多久？ | 两组环比加实际连续下降/上升区间，不直接推断排名或广告带动 |
| 支付转化率 | 较长周期效率与近期是否一致？ | 用百分点比较；周序列反复则说明波动，保留成交样本限制 |
| 加购率 | 兴趣信号是否延续，是否单周冲高后回落？ | 对照7天/30天与此前周度常见范围，不将行为率直接当未来成交 |

结论用“近期回落、30天仍增长”“两个周期均减少，最近连续回落”“反复波动，尚未形成持续增长”等与实际证据匹配的表达。按完整精度判定方向；显示四舍五入后相同不能证明完全持平。连续变化必须有相邻周证据；缺失则降级结论。

## 简明展示与执行回到主线

当前指标仅展示一句综合结论和有序短段证据。通常用三段分别给7天、30天、自然周的关键原值和变化；必要时增加一段最重要的解释或限制。若某尺度缺失，原位置简短标明；不凑结论。日期可集中放在公共口径处。

先写支持结论的最关键证据，再补足其余尺度，允许按重要性调整顺序。每段围绕一件事，关键数字和结论短语局部加粗或用一致颜色强调；事实与解释清晰区分。完整表格和计算留给图表或按需证据，不在分析正文重复铺开。
