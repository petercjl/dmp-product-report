# 如何分析推广策略的7天、30天与自然周

触发：推广数据已取得，需要判断当前指标的变化或撰写推广分析。检索问题：该场景的该指标在三个时间尺度上能确认什么，哪些区间或缺失限制结论？

首次进入知识节点先读SCHEMA.md、index.md、log.md最近记录，再批量读[来源边界](../topics/analysis-boundaries.md)和[推广三尺度方法](../topics/promotion-three-horizons.md)。日期有歧义才调用周期路线；关键指标、人群细则和source-manifest维护清单继续延后加载。

输入：商品、场景、12周期原值/类型/状态/日期核实情况。输出：逐场景逐指标的一句结论、有序短证据和必要限制；保留区间与缺失。完成后返回SKILL第4步，再进入渲染，模块完成后再由综合节点撰写概览。
