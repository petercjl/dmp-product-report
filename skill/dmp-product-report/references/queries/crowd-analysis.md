# 如何分析人群构成的7天、30天与自然周

触发：人群数据已取得，需要判断规模、成交构成或比例表现。问题：同一指标在三个尺度能得出什么结论，分类返回范围、分母和缺失如何限制判断？

首次进入知识节点先读SCHEMA.md、index.md、log.md最近记录，再批量读[来源边界](../topics/analysis-boundaries.md)和[人群三尺度方法](../topics/crowd-three-horizons.md)。周期有歧义才加载周期路线；其他模块细则与source-manifest维护清单继续延后加载。

输入：12周期的平台合计、分类原值/状态、时间与定义。输出：4指标的一句综合结论、编号短证据及必要限制，附独立的分类分母/合计核对。完成后返回SKILL第4步，再进入渲染，概览最后综合三个模块。
