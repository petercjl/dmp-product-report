# 分析节点
问题：哪些数据可直接比较，哪些缺口限制判断？首次进入读取结构页，再读取 [方法页](../topics/analysis-boundaries.md)。输出模块事实、判断、假设与缺口，返回主线第4步；来源清单与历史评估不加载。

关键指标进入[三尺度分析方法](../topics/metrics-three-horizons.md)，按指标合看7天、30天和8周，生成一句结论与编号证据。概览最后进入经营解读路线，综合三个模块后撰写。推广进入[推广三尺度方法](../topics/promotion-three-horizons.md)，逐场景逐指标形成结论与编号证据；人群进入[人群三尺度方法](../topics/crowd-three-horizons.md)，分别核对分类、合计和比例，逐指标形成结论与编号证据。
