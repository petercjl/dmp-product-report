# 如何分析7天、30天与8周的关键指标

触发：关键指标数据已取得、正在制定分析方法或撰写该模块分析。检索问题：近期变化与较长周期是否同向，销售额的量价贡献是什么，完整周是否支持持续性判断？

首次进入知识节点先读SCHEMA.md、index.md和log.md最近记录；随后批量读取[来源边界](../topics/analysis-boundaries.md)和[三尺度分析方法](../topics/metrics-three-horizons.md)。周期已核对时不重读周期主题；日期存在歧义才进入periods.md路线。

输入：商品与12周期计划、经营原值/状态/来源。输出：每个指标的一句跨尺度综合结论、有序短段关键证据和必要限制；计算依据独立保存。缺失项明确说明，概览在三个业务模块完成后综合撰写。返回SKILL主线第4步完成分析，再进入第5步渲染。推广、人群详细知识和source-manifest维护清单继续延后加载。
